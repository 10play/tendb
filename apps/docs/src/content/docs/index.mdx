```bash
tendb branches create my-feature   # copy-on-write branch DB, ready in ~5s
tendb psql my-feature              # auto SSM tunnel + psql
tendb console                      # Neon-style dashboard on localhost
tendb ci ensure 42 | tail -1       # CI: connection URI as the last stdout line
```

## Built on DBLab Engine

tendb stands on [DBLab Engine](https://github.com/postgres-ai/database-lab-engine)
by [Postgres.ai](https://postgres.ai) — the open-source engine that does the
heavy lifting of ZFS thin cloning and copy-on-write branch databases. tendb
adds the AWS packaging around it: Terraform provisioning, SSM transport, the
CLI, the web console, and the CI contract.
